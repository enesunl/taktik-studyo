## Teslim doğrulaması

| Kontrol | Sonuç |
|---|---|
| Orijinal kaynak bütünlüğü | 511/511 SHA-256 eşleşti; mevcut checkout temiz |
| Yerel kopya bütünlüğü | 511/511 orijinal dosya birebir korundu |
| Build | Başarılı; yeniden üretilen dist/backend.js mevcut bundle ile birebir aynı |
| Mevcut testler | 9/9 geçti |
| Saha regresyonu | Takım/formasyon, sürükleme, oyuncu/yedek değişimi, çizim, fullscreen, karşılaştırma ve taslak kontrolleri geçti |
| Yerel sunucu | Ana sayfa, karşılaştırma, asset, /lineup rewrite ve dosya erişim sınırları: 10 kontrol geçti |
| Frontend secret taraması | TURNSTILE_SECRET_KEY, sb_secret_, service_role, LINEUPS_SECRET_KEY ve database password ifadeleri production dosyalarında yok |
| Kaynak paketi taraması | Gerçek secret key/token, private key, credential içeren DB URL ve JWT desenleri bulunmadı |
| Supabase secret okuma | Yapılmadı |
| Canlı mutasyon/yayın | Yapılmadı |
| Gerçek tarayıcı / Turnstile E2E | Bu teslimde çalıştırılmadı; yerel paylaşım origin sınırı rehberde açıklandı |

Server-side kaynaklarda secret **değişken isimleri**, SQL'de `service_role` rol adı,
ve testlerde açıkça sentetik fixture dizeleri korunmuştur. Bunlar gerçek secret
**değerleri** değildir. Public Supabase anahtarı ve Turnstile site anahtarı yerel
public yapılandırmada ve tarayıcı bundle'ında bulunur.

`npm ci` kurulumu bu ortamda yeniden indirilmedi: doğrulama mevcut aynı lockfile'a
ait kurulu bağımlılıklarla yapıldı. ZIP'e node_modules veya bu doğrulama sırasında
kullanılan sembolik bağlantı alınmadı. Node.js 22+ ve npm bilgisayarında gerekir.
